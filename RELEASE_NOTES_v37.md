# JUNIOR U16 v37

- Новая главная с актуальными играми, быстрым доступом к таблице, личному прогнозу и аналитике.
- Единая типографика Manrope, спокойная палитра, светлая и тёмная темы, русское окно выбора даты.
- Компактная лента матчей с построением видимых карточек, фильтрами и сохранением позиции разделов.
- Переработанные матч-центр, профили команд, таблицы, игроки, прогнозы и аналитические разделы. Вкладки протокола остаются доступными при прокрутке.
- Календарь появляется до окончания проверки LIVE. Ошибки загрузки и сохранённые данные обозначаются явно.
- Исправлены гонки избранного, проверка ответов перед записью кэша, потеря сведений о неполноте и обработка матчей без опубликованного протокола.
- Исправлено определение финального счёта для сегодняшних матчей без времени начала в часовом поясе Москвы.
- Добавлены проверки навигации, сохранений, офлайн-протокола, закрытия экрана во время запроса и работы на узких экранах.

Изменения серверного API подготовлены отдельно. Эта версия приложения не включает автоматический деплой сервера. Доступность свежих данных зависит от ФХР и API.
