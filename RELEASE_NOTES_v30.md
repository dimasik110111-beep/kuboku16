# JUNIOR U16 v30 · LIVE & RELIABLE

## Исправления данных и прогноза
- Счёт и ID матча из ФХР корректно читаются как из чисел, так и из строк; детализация LIVE сохраняет отметку об овертайме.
- Числовые ID клубов разбираются без падения загрузки, неверные записи отсеиваются клиентом.
- При смене этапа статистики устаревшие сетевые ответы больше не перезаписывают выбранный этап. Быстрый повторный выбор запускает новый запрос, а не пропускается флагом загрузки.
- Страница клуба сначала показывает сохранённую статистику, а затем обновляет её из ФХР; при сбое сети доступны последние сохранённые данные.
- Сравнение сценариев больше не меняет состояние во время построения виджета.

## Проверка
- Добавлены регрессии для строкового счёта и ID, включая ID клуба и статус овертайма из LIVE-детализации.
- GitHub Actions запускает анализ, полный набор Flutter-тестов, release-сборку и проверку постоянной подписи перед публикацией APK.
